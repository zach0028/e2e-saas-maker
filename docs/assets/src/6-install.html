Try it

Three commands from idea to build.

› /plugin marketplace add zach0028/e2e-saas-maker
› /plugin install e2e-saas-maker@e2e-saas-maker
› /e2e-saas-maker:frame "a booking page for yoga teachers"
# ~12 questions, one approval, then: /e2e-saas-maker:build

You are asked twice: "Approve this scope?" at the start, "Go live?" at the end. Everything in between runs on its own — and stops to ask only when a decision is really yours.

The five laws

Agents write plausible code.
These rules make it correct.

01

No code without an approved plan

The planner checks the story against real code first. A false premise stops everything.

02

The writer never reviews

Every review starts in a fresh context, with no memory of why the code "should" work.

03

Closed by default

No verdict line, no integration. A missing record is never a success.

04

Scripts run the checks

"Tests pass" from an agent proves nothing. The script runs them and pins the exact git tree.

05

Main and prod stay yours

Stories land on a build branch. Production steps wait in a ship log for your go.
